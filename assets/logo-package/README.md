# Gem Infotech Logo Package

Generated for Gem Infotech website use.

## Recommended Website Files

- `logo-header-light-bg.png` / `logo-header-light-bg.webp`  
  Use in the main website header or any white/light background.

- `logo-header.png` / `logo-header.webp`  
  Use on dark emerald, charcoal, or photo backgrounds.

- `app-icon.png`  
  Use for square social previews, app icons, and profile images.

- `favicon/favicon.ico`  
  Use as the browser favicon.

- `favicon/apple-touch-icon.png`  
  Use for Apple home-screen icons.

- `favicon/android-chrome-192x192.png` and `favicon/android-chrome-512x512.png`  
  Use in the web app manifest.

## Full Export Sets

- `png/` includes transparent PNG exports for horizontal logos and icons.
- `webp/` includes optimized web exports.
- `favicon/` includes browser and touch icon assets.
- `source/` includes the generated source and presentation files.

## Brand Colors

- Deep emerald: `#053b2f`
- Forest emerald: `#0f4a3e`
- Warm ivory: `#f7f1e7`
- Muted gold: `#d6a24a`

## Notes

Use the light-background version in the current site navbar for best contrast. Use the ivory/gold version only on dark backgrounds.
